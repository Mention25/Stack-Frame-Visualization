# 嵌套调用示例

`main → foo → bar` 已作为“输入汇编”的默认示例，不再有独立教学页面、阶段讲解或观察点。已有浏览器草稿优先恢复，也可以从示例菜单重新载入。

该示例执行 21 条指令，返回 `2 × 7 + 1 = 15`。汇编为独立手写实现，采用 System V AMD64 参数约定并保留帧指针，不来自课程实验二进制。虚拟地址、有限栈空间、零初始寄存器和入口返回标记是解释器约定，不代表真实运行环境。

界面复用原作者的三栏组件；左栏编辑代码，执行后可单步、回退、播放或拖动进度。输入能力与限制见 [ASSEMBLY.md](ASSEMBLY.md)。

维护检查：`npx tsc --noEmit`、`npm test`、`npm run build`。`tests/lesson.test.cjs` 核对调用、栈对齐、返回值和原生汇编 fixture 的一致性；具备 GCC 的环境会对内置示例进行原生执行对照。
