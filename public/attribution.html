来源与许可说明

原项目声明其教学材料来自 Michael Walfish 的 NYU CSCI-UA.0202 Operating Systems 课程。本部署基于上游提交 8914d54ba0dd263ded7d75d31a2e607e93ea80b1。

Mention25 维护新增的汇编教学解释器、输入编辑器、动态栈视图、执行历史与独立示例，并负责 GitHub Pages 部署。页面的可视化组件与设计沿用上游项目；当前仅提供汇编输入页面。本页不代表原作者、NYU 或课程团队的官方发布或背书。

适用范围

默认的“输入汇编”模式内置独立的 main → foo → bar 示例，可编辑并执行 AT&T / Intel 汇编；状态由教学解释器计算。示例采用 System V AMD64 参数约定并保留帧指针，虚拟地址与寄存器初值不代表实际运行环境。

页面在浏览器中解释执行受支持的指令，自动计算栈、寄存器和控制流；代码地址使用虚拟编号，不生成真实机器码。页面用于通用原理演示，不读取或运行课程实验二进制，不能用演示状态作为实验程序的标准答案。
